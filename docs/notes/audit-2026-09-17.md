# Audit campaign — 2026-09-17

Recursive hardening pass over the uncommitted Helix tree. 21 findings confirmed by an
adversarial review workflow; every confirmed finding was fixed at root cause, regression-
tested, and the tree verified end to end. No commits made (tree mixes user WIP).

## Compiler correctness (fixed, differential regressions added)

- **Loop-bound snapshot (helix-ir/build.rs)** — JIT re-read a loop end bound that the
  body mutated (`for i in 0..n { n = 0; ... }` ran once, interpreter runs 3). End is now
  snapshotted into a fresh preheader temporary; `for_loop_end_is_evaluated_once` pins it.
- **i32 constant folding width (helix-ir/passes/const_fold.rs)** — `I32(MAX)+1` folded to
  `I64`; folds are now width-preserving, mixed-width folds rejected, `MIN / -1` and `% -1`
  stay runtime traps. Pinned in review_regressions + jit_pipeline.
- **Analysis conservative contract (helix-analysis)** — equal-constant ZIV now yields
  unknown distance/star directions (not a false independence proof); non-affine/zero-stride
  sole writes veto parallelization while invariant offsets are judged by IV coefficient
  (injective, not a hazard); used non-reduction header phis and zeros-in-loop allocation are vetoed,
  recognized reductions and provably-dead phis are not; Sub reductions require the
  accumulator on the left. 83 tests green. Iteration 2 fixed two false-veto regressions
  the first wave introduced (dead header temps, invariant-offset sole writes) and matched
  the backend's extraction gate.
- **Backend lowering (helix-backend)** — i32 div/rem panic payload width; float fallback
  returns in panic paths; f32 capture native width; parallel reduction seed counted once
  (7 + 100000 printed 100056 before). 47/47 jit_pipeline.
- **Zeros-in-loop contract** — per-iteration allocation is now vetoed by analysis up front
  (allocation identity is unmodeled); the regression pins the veto plus byte-exact
  sequential-JIT/interpreter parity.

## Iteration 2 — reviewing the fix-wave diff itself (2026-09-17)

The diff produced by iteration 1 was re-audited (3 review lenses → adversarial
verify). Two findings survived verification; both fixed with regressions:

- **measure→recompile editor desync (web/app.js)** — measuring a named example
  adopts `<adhoc>` but left the editor empty, so Recompile would POST empty
  source. `measureCustom` now writes the measured source into `#custom-src`
  at the commit point; pinned in `app.test.mjs` (Recompile posts the measured
  source).
- **Estimator undercharged allocations (pipeline.rs)** — `zeros(n)` cost a
  flat 1, so allocation-only programs passed the interactive/custom budgets
  while the interpreter allocated and checksummed every element. `zeros(n)`
  now charges its resolved length and fails closed for unknown lengths, as
  unknown loop bounds already do; pinned in the work-estimate test. All 39
  observer tests passed after this change.

JS-side estimator already charged max literals; no change needed there.

## Iteration 3 — remaining correctness review

- **Syntax diagnostics** — the client now displays lexer/parser errors alongside
  semantic errors, exposes their actual messages, keeps SOURCE accessible when
  lexing produces no tokens, and reports compilation errors rather than success.
  Node regression passes for lexer/parser artifacts; the live parser-error path
  showed the expected banner and locked stages with no console errors. Screenshot
  capture timed out; verification evidence is the browser accessibility snapshot.
- **Float copies lose -0.0 (helix-ir/build.rs)** — `copy_value` expressed float
  copies as `x + 0.0`; const-fold evaluates that to +0.0, so `let y = x` erased
  negative zero (`1/y` printed +inf where the interpreter prints -inf). Copies
  are now same-type `Inst::Cast`s; the backend lowers identity casts to the
  value itself. Differential JIT/interpreter regression pins -inf for both f64
  and f32 copies.
- **Short-circuit inside call args panicked (helix-ir/build.rs)** — `scan_expr`
  skipped Call subtrees, so `print(true && false)` popped the `$sc` reservation
  stack empty and panicked. scan_expr now descends builtin and user call
  arguments; construction+verify regression covers builtin/user/nested calls.
- **Cast copies blinded pre-optimization analysis (helix-analysis)** — the new
  cast-based copies were opaque to `access.rs::classify` (non-affine) and
  `canon.rs::bound_of` (only peeled the legacy `x + 0` shape), so copied IV
  indices and cast-wrapped loop bounds degraded provable DOALL loops to
  Sequential verdicts. Same-type casts are now transparent to both; pinned by
  `copied_iv_stays_affine_through_cast_copy`; 83 analysis tests green.
- **Six client defects (web/app.js, style.css)** — measurement failure kept an
  enabled-retry-less empty state until recompile; log-scale bars had an implicit
  1 ms origin (negative widths / reversed order below 1 ms); OPT headers were
  click-only divs; the SSA checkbox toggled a class CSS ignores; instruction
  reductions displayed `±0`; CFGs rendered past the panel edge with no viewBox.
  All fixed with VM regressions (retry control, log geometry, aria-expanded,
  side-by-side class, delta signs, per-function viewBox); both Node suites pass.

Iteration-3 gates: workspace `cargo test` 46 suites / 0 failures,

## Iteration 4 — adversarial review of the newest surfaces (2026-09-17)

19-agent review sweep over the tree after the metrics/cast changes; 13 verified findings
deduplicated to 11, all fixed with regressions:

- **Compiler (wrong-code, P1)** — `canon::bound_of` peeled every cast, so a
  narrowing cast (`4294967297 as i32 as i64`) invented a false exact loop window
  and parallelized a distance-1 recurrence. Peeling is now same-type identity
  only; narrowing bounds stay symbolic. Separately, i128 mathematical
  coefficients treated wrap-capable `i64` runtime arithmetic as injective
  (`(i*2^32)*2^32` writes every element to slot 0). Affine classification now
  carries an `exact` (no-wrap) flag per intermediate operation: sole writes
  need a no-wrap proof or a same-width odd modular permutation; paired
  dependence proofs require exact forms. Wrap-capable even strides
  conservatively veto (documented false-veto tradeoff; gcd_box golden reason
  updated). 92 analysis tests + 50 jit_pipeline green.
- **CLI stats scope (P2)** — the JIT stats line sampled `compile_start.elapsed()`
  after `run_main`, charging the whole execution to "compile". Now frozen right
  after compile: `[jit] lower-to-run total X ms (compile X ms, run X ms) ·
  planned parallel regions N`. Source-order regression pins the boundary
  sequence; help text documents measurement scopes (interp checksum includes
  final arrays; native stdout is not checksum-equivalent evidence) and corrects
  exit codes, `--quick`, and `--host` claims.
- **Client (P2 ×5 +2 review follow-ups)** — measureCustom no longer overwrites
  `art.exec` (the fabricated "matches observer output" parity line is gone;
  samples live in `art.bench`); overlapping compiles can no longer corrupt the
  button label; a failed example selection keeps the custom buffer; CFG
  tooltips mount in the visible panel; AST labels accept serde's scalar-string
  Type shape (`Ty ?` → `i64`); measurement completion preserves edits typed
  while it ran; a failed browser run shows observer evidence undiluted.
  21 check groups in `app.test.mjs`.
- **Browser estimator (P2 ×2)** — block comments and scalar literals no longer
  count as work (`print(3000000)` was refused; `zeros(3000000)` still is);
  sibling loops add trips instead of compounding per `for` line (three
  sequential `0..2` loops were estimated at 1e9). Loop subtrees nest, sibling
  bodies add, allocations charge their length.
- **Standalone export (P2)** — the export kept `/style.css`, `/vendor/d3`,
  `/app.js` and font URLs, so the saved "offline" file was an unrendered
  shell. Everything is now inlined (fonts as data: URIs, scripts inline with
  `</script` escaped); export test asserts zero external refs, and the saved
  file was verified at 516 KB with no server running.

- **CLI `helix run`** now prints a one-run stats line to stderr on both

  checksum 0x…` / `[jit] total 6.7 ms (compile 6.4 ms) · parallel regions 2`.
