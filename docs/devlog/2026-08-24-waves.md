# Devlog — 2026-08-24: Waves 1–3 (parallel crate construction)

## How the compiler got built

Development ran as parallel agent waves on **disjoint crates**, coordinated by
interface contracts (`docs/notes/interface-contracts.md`) written up-front:

| Wave | Crates | Result |
|---|---|---|
| 1 | helix-syntax, helix-runtime (+ sema by hand) | 86 + 41 + 12 tests |
| 2 | helix-engine (interpreter), helix-ir (CFG/SSA/7 passes) | 56 + 36 tests |
| 3 | analysis finish, backend, bench, observe server — in flight | |

Each wave's agents read the same frozen spec + contracts; deviations came back as
explicit `contract_deviations` lists instead of silent drift.

## Bugs the cross-agent process caught

1. **sema dropped call arguments** after type-checking (`TypedExprKind::Call` had no arg
   subtrees). The interpreter agent needed them; fixed by carrying typed args in
   CallTarget. Lesson: contract reviews must trace *data flow*, not just types.
2. **saxpy.hx used digit separators** (`33_554_432`) outside the frozen grammar — lexer
   rightly rejected. Example fixed.
3. **count_primes_sieve.hx wasn't a sieve** (no stride); engine tests pinned the wrong
   result → bench agent rewrites with stride-i inner loop.
4. IR agent found and fixed three soundness bugs in its own passes via the verifier-gate
   (phi arity desync after edge removal; DCE dominance violation; chain-merge phi
   re-keying) — each now has a regression test named after itself.
