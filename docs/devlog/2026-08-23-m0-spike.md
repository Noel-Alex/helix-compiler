## Hard-won API facts (cranelift 0.135.0, verified against installed source)

These differ from most tutorials/docs found online — worth citing in the report:

1. **`BlockArg` is new**: terminator args are `&[BlockArg]`, wrap values as
   `BlockArg::Value(v)` (`cranelift::codegen::ir::BlockArg`). Old `&[Value]` code does not compile.
2. **MemFlags redesign**: flags live in a per-function `MemFlagsSet`;
   `MemFlagsData::trusted()` is the base constructor and `with_notrap()/with_aligned()/
   with_readonly()` are builders — plain `.notrap()`/`.aligned()` are now *getters* returning bool.
3. `cranelift_native::builder()` → `.finish(flags)`; no `new_host_isa()`.
4. `finalize_definitions()` returns `ModuleResult<()>`; pointers via `get_finalized_function`.
5. All cranelift-* pinned `=0.135.0`; mixed minors don't link (shared `ir::*` types).
6. Borrow discipline: copy `block_params(...)` values into locals before `ins()` — the builder's
   borrow of the function conflicts otherwise.
